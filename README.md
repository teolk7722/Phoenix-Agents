# PhoenixLabs – Subagentes de Claude Code

Subagentes para la agencia PhoenixLabs (Alicante).

| Agente | Para qué |
|---|---|
| `disenador-web` | Diseño UI/UX: identidad visual, paleta, tipografía, componentes, estructura de páginas |
| `desarrollador-frontend` | Código HTML/CSS/JS, Tailwind, Astro, React/Next.js |
| `seo-copywriter` | SEO local y textos de venta para Alicante y la Comunitat Valenciana |
| `revisor-calidad` | Auditoría antes de entregar (responsive, WCAG, rendimiento, legal); solo informa |
| `automatizaciones-ia` | Automatizaciones, chatbots, integraciones y despliegue en Linux |

## Instalación

- **Para todos tus proyectos:** copia `.claude/agents/*.md` a `~/.claude/agents/`.
- **Solo para un proyecto:** copia la carpeta `.claude/agents/` a la raíz del proyecto.

Comprueba que se cargan con `/agents` dentro de Claude Code.
